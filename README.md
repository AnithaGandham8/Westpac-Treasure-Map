# Westpac Treasure Map

Westpac Innovation and Coding Competition 2026.

Rewards Westpac already pays for, finally in sight: Treasure Map, Skip & Save, Me vs Me.

## Files
- `index.html`: phone frame, tabs (Map, Pot, Missions), hidden demo panel (press D)
- `styles.css`: GEL tokens, phone frame, AI-accent chips
- `data.js`: mock shops, card tiers, Ana's transactions, bills, goal
- `engine.js`: deterministic habit and mission logic
- `app.js`: tabs and scenario state

## Run locally
    python3 -m http.server 8080
Then open http://localhost:8080
